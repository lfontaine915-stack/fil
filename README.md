# Fil

Mon fil perso, à faire défiler comme TikTok, sur les énergies renouvelables, le nucléaire, les innovations du bâtiment et les grands chantiers.

- `sources.yaml` : les sites et chaînes YouTube suivis (modifiable)
- `filtres.yaml` : mots qui écartent un contenu, mots de chaque thème (modifiable)
- `robot/` : script qui récupère les flux (lancé 6 fois par jour par GitHub Actions)
- `docs/` : l'appli (HTML/JS, installable sur téléphone)
- `GUIDE.md` : mise en ligne et installation
